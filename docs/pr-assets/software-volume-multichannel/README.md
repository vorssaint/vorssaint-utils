# Output-layout screenshots

Captured on macOS 27.2 on 7 November 2026. These are actual application UI, without generated or retouched controls.

- `menu-stereo.png`: native panel capture on Mac Studio, with Stereo beside Output and Vorssaint Audio selected.
- `menu-hdmi-5.1.jpg`: user-provided MacBook Pro capture during direct HDMI playback to Samsung QCQ90S. The panel shows 5.1; the accompanying diagnostic log confirmed six-channel, 48 kHz PCM transport. The capture includes the system menu bar and a cropped panel bottom. It does not verify individual physical surround speakers.
- `settings-options.png`: native Settings-window capture with the output badge and Options expanded, including the settings-only privacy and removal actions. AirPlay was selected at capture time; the fallback preference is enabled.

Stereo and 5.1 illustrate different selected output configurations. Settings is represented by one capture. Voice recordings and diagnostic logs are excluded.
