# Blank document templates

These six blank document templates are from [MenuWish](https://github.com/Goonwb/MenuWish/tree/327b4cf8177d9b29fbfc87ed7bc461fb3fc2612b/MenuWish/Resources/Templates) (Copyright (c) 2026 Goonwb, MIT; see LICENSE-MenuWish.txt). They are copied byte-for-byte. The exclusive-write creation pattern is also based on MenuWish. The original project states the iWork templates were created with version 26.3.1; older versions have not been verified. The templates are bundled data, not application executables.

Text and Markdown are created empty; JSON starts as an empty object. No Office or iWork app needs to launch to create a file. Review redistribution provenance and compatibility of the proprietary-format blank documents before release.
